# 기술별 skill 다수, 범용 대형 팩

**왜 넣지 않는가**: 모델이 이미 아는 일반 지식을 skill로 넣으면 설명이 context를 차지하고 자동 로딩이 빗나간다. 웹 서비스 위주 규칙이 다른 종류의 프로젝트에 섞인다.

**대신**: 템플릿에는 예시 하나(`kotlin`)만 둔다. 프로젝트가 실제로 반복해서 틀린 것만 `.harness/project/skills/`나 `coding-standards.md`에 넣는다. 기계적으로 판정되는 규칙은 lint로.

**다시 검토할 조건**: 같은 기술 규칙이 여러 프로젝트의 `project/skills`에 반복해서 생길 때 — 그때 템플릿으로 올린다.
